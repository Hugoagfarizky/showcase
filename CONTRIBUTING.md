# Panduan Kontribusi

Showcase ini hanya berisi hasil build dari repo privat. Kontribusi langsung ke repo ini tidak diterima; perubahan dilakukan di repo sumber masing-masing.

## Melaporkan masalah

Kalau ada link yang rusak, aset yang tidak termuat, atau halaman yang error, buka issue di repo ini dengan menyertakan:
- URL yang bermasalah
- Perangkat dan browser
- Screenshot kalau ada

Untuk masalah keamanan, ikuti `SECURITY.md`.
