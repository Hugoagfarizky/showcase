About

About this showcase

What this site is, why it exists, and how it is built.

What is this?

This showcase hosts the deployed builds of private repositories. The source code stays private; only the compiled output is published here, so the apps can be shared and demoed without exposing the codebase. Each app is a single-page or multi-page static site served from its own subfolder, which keeps the URLs stable and shareable.

Why a separate showcase repo?

Most of the source repositories are private (personal experiments, coursework, and prototypes). GitHub Pages on a free plan only serves public repositories, so the builds are collected here into one public site. This keeps the source private while still giving every app a public, permanent link.

How it works

  • Build locally / in CI — each app is built with its own toolchain (Vite, Next.js static export, Flutter web).
  • Base path — apps are built with a base path like /showcase/monorepo/ so assets resolve correctly under the subfolder.
  • Collect — the compiled dist/ (or out/, build/web/) output is copied into a matching subfolder of this repo.
  • Publish — GitHub Pages serves the whole folder tree; each subfolder becomes its own URL.
  • Auto-update — pushing to a source repo triggers a rebuild and a redeploy of this site.

Privacy & data

  • No backend and no database — every app runs entirely in the visitor's browser.
  • User data (notes, tasks, pantry, etc.) is stored in localStorage / IndexedDB on the visitor's own device.
  • Nothing is uploaded, tracked, or sent to any server. No analytics, no telemetry.
  • Third-party APIs (TMDB, Open-Meteo, GitHub REST) are called directly from the browser where needed.

Project structure

  • / — this landing page.
  • /monorepo/, /repoforge/, /gitcraft/ — React/Vite apps.
  • /first-dev-projects/ — index of 20 mini-projects, each in its own subfolder.
  • /first-dev-projects/proyek-XX-*/ — individual static apps (HTML/CSS/JS).
